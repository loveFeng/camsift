## 其他地方的说明

- **架构决策的"为什么"** → `docs/adr/`

- **项目约定**（bat 编码与行尾、数据库访问口径、队列语义等）→ `.workbuddy/memory/MEMORY.md`

## 维护约定

- 新增文档请同步更新本表；**文档头部写明状态**（现行 / 进行中 / 已被取代 / 档案）
- 一份文档若被取代，**不要直接删除** —— 移入 `_archive/` 并在本表说明原因
  （项目的一贯思路：删前保全，见 ADR 0001）
- 路径改名后记得全局搜一遍引用：`grep -rn "旧文件名" --include="*.md" --include="*.py" .`
