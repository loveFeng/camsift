## 五、维护约定

- **新增文档请同步更新本页**；每份文档头部写明状态（`现行` / `进行中` / `已被取代` / `档案`）
- 一份文档被取代 ⇒ **移入 `_archive/` 并在下表说明原因**，不要物理删除
- 路径改名后全局搜一遍引用：`grep -rn "旧文件名" --include=*.md --include=*.py .`
- **数字真源 = 现库 SQL 实测**，文档只留结论与量级、写清复现命令；最易失真的三样是
  **数字、列数、行号** —— 落点写函数名，不写行号
- **不要往历史报告里补待办** —— 只有 [`待办与风险.md`](待办与风险.md) 一个登记簿
