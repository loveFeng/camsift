# 监控视频 AI 筛选工作台

把监控录像里的**移动侦测误触发片段**挑出来，按置信度分级移动到回收目录。**程序只分析、打分、分级移动，永不删除**——最终删除由你手动完成。

## 核心能力

| 需求 | 实现位置 |
|------|---------|
| 网页审核视频 | 「审核工作台」逐条（带快捷键）+ 「批量浏览」九宫格（分页） |
| 检查执行过程 | 「执行进度」页（后台任务实时面板 + 批次进度 + 吞吐/ETA） |
| 为什么删/留 | 每条都展示**判定依据链**（逐项加分明细） |
| 误判归因 | 标记「误判要保留」后自动归因，结果常驻显示，并汇总到「误判分析」页 |
| 🔊 音频复核 | 判删候选抽音轨 → 人声检测（FSMN-VAD）→ 转写全文给人看 → LLM 判断是否有用（阿里 FunASR + ollama/qwen3），防止画外有内容的片段被误删 |

**扫描与分析都跑在后台线程里**：启动后可以随意切页签、继续审核，进度每秒自动刷新，随时可停止（在当前文件处理完收尾，已完成的写入不丢）。

## 判定逻辑（一句话）

录像是动了，但动的是什么？**没检出人/车，只有画面变化** → 判为环境误触发（树叶/光影/车灯），建议清理。检出人/车/动物 → 保留。**画面无人但有音轨的候选，清理前会先过音频复核**（有声事件捞回，见 `docs/开发计划.md` §3.6）。

分三档：

- **建议清理（trash）**：无目标且画面变化微弱
- **需人工确认（review）**：画面有动静但无目标，或存在未达阈值的疑似目标
- **建议保留（keep）**：检出人/车/动物

## 快速开始

**双击项目根目录的 `启动工作台.bat`** 即可。

它会自动完成：检查虚拟环境 → 检查依赖（缺了就装）→ 检查 YOLO 模型 → 检查端口占用 → 启动服务 → 打开浏览器。

浏览器打开 **http://localhost:8501**

停止服务：在窗口按 `Ctrl+C`，或双击 `停止服务.bat`

> 完整的从零开始说明、完整使用流程、常见问题排查见 **[docs/启动与使用指南.md](docs/启动与使用指南.md)**

命令行启动（等价效果）：

```bash
cd E:/code/video-search
.venv/Scripts/python.exe -m streamlit run src/ui.py --server.port=8501
```

## 使用流程

1. **「设置与扫描」页** 填三个路径：
   - `source_root`：视频源根目录（移动硬盘，只读）
   - `trash_root`：分级回收目录（**必须与源同一物理盘**，否则移动会拒绝）
   - `work_dir`：本地工作目录（数据库/缩略图，放 SSD）
2. 点 **🔍 启动扫描（后台）**，再点 **🤖 启动 AI 分析（后台）**。任务在后台跑，下方面板实时显示进度、速度、预计剩余，可随时点「停止任务」
3. **「审核工作台」** 逐条审核：看缩略图 + 判定依据链 → 确认清理 / 误判保留
   - 快捷键：`空格` 确认清理　`回车` 误判保留　`←` `→` 翻条　`P` 播放器打开　`V` 生成网页预览
   - 判为误判后，归因结果会显示在页面顶部（不会一闪而过）
4. **「批量浏览」** 分页多选，批量移入回收目录后**自动生成清单 CSV 与空间统计**
5. **「误判分析」** 页看误判原因分布与调参建议

> 修改阈值后要先点「保存配置」再启动任务，否则用的还是旧配置。

## 目录结构

```
src/
  config.py     配置（阈值/路径/打分权重）
  db.py         SQLite 数据层（含原始检出与判定依据链）
  scanner.py    ffprobe 元数据扫描（串行读盘，断点续跑）
  analyzer.py   抽帧 + 动静检测 + YOLO 目标检测 + 打分
  feedback.py   误判归因（回看原始检出，归类原因，给调参建议）
  mover.py      分级移动 + 撤销 + 清单/空间统计（不含任何删除）
  jobs.py       后台任务管理（独立线程 + 进度 + 停止，进程级状态）
  hotkeys.py    键盘快捷键（注入 JS 按按钮文案定位）
  cli.py        命令行入口（想脱离 UI 长期跑时用）
  ui.py         Streamlit 审核工作台
scripts/
  download_model.py  下载 YOLOv8n ONNX 模型
  make_samples.py    生成测试样本
  selftest.py        核心逻辑自测
```

## 关键设计

- **保存原始检出**（含未达阈值的）：否则事后无法回答「为什么误判」。
- **解不开的片段默认保留**：私有编码（H.265+/Smart H.265）绝不因技术失败判为垃圾。
- **移动硬盘全程只读**：数据库、缩略图全落本地 SSD，仅执行移动时写一次源盘。
- **分级回收目录**：`_Trash/A_高置信可批量删除` / `B_低置信建议抽查`，手动删时看文件夹名即可。
- **程序永不删除**：`scripts/selftest.py` 内置代码审计，确认 src/ 下无 `os.remove`/`shutil.rmtree`/`unlink` 调用。
